DEPLOYMENT
----------
1. Extract the ZIP.
2. Upload all files/folders to the GitHub repository root.
3. Replace the previous Step 6 website files.
4. Commit/push changes.
5. GitHub Pages can serve index.html directly. No build step, Node.js runtime or backend is required.

FALLBACK IMAGE
--------------
images/wood-fallback.svg is a locally included procedural wood-grain fallback. If a remote image is unavailable, script.js swaps the image to this local SVG so the layout remains intact.

PERFORMANCE / ACCESSIBILITY
---------------------------
- Uses IntersectionObserver for reveal animations.
- Uses requestAnimationFrame for cursor/parallax/tilt work.
- Uses CSS transforms instead of layout-heavy animation.
- Disables excessive 3D movement on touch-sized screens.
- Respects prefers-reduced-motion.
- Product cards are keyboard focusable and support Enter/Space.
- Modal supports Escape-to-close.
